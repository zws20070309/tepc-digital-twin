# VV 计划（验证与确认判据，预注册容差）

判据在实现前注册（阈值来源为数值测试需求，不是物理符合性标准）。
下列判据由 tests/ 下的自动化测试执行（行内标注 外部核对 者除外），最终以干净 MATLAB 进程
（matlab -batch runAllTests）出结果。
